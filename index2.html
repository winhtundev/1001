မြန်မာစာ အမှတ်ပြည့် Cheat Sheet

Exam Ready

အက္ခရာစဉ် • သဒ္ဒါ • စကားပြေ • ကဗျာ • စာစီစာကုံး ဖော်မြူလာ

GOLDEN RULE • အမှတ်ပြည့်ယူနည်း ၁၂ လုံးစီ = ၆ မှတ်

စာမေးပွဲမှာ အက္ခရာစဉ် မေးခွန်းမြင်တာနဲ့ ဒီ (၂) ဆင့်အတိုင်းပဲ စစ်ပါ

STEP 01 (အရင်ဆုံးကြည့်ရန်)

၁။ ရှေ့ဆုံး ပင်မဗျည်း (က - အ) တူလား၊ မတူဘူးလား?

ပေးထားတဲ့ စကားလုံးတွေရဲ့ ရှေ့ဆုံးဗျည်းတွေက တစ်လုံးနဲ့တစ်လုံး မတူရင် (ဥပမာ - ပန်းနာမည်တွေလို က၊ ခ၊ ဂ၊ င၊ စ၊ ဆ ကွဲနေရင်) ဇယားဆွဲစရာ လုံးဝမလိုဘူး! က ကနေ အ (၃၃) လုံး အစဉ်အတိုင်း တန်းစီချလိုက်ရုံပဲ။

STEP 02 (ဗျည်းတူနေမှ သုံးရန်)

၂။ ပင်မဗျည်းချင်း တူနေရင် ကော်လံ (၃) ခု ခွဲချပါ!

ဗျည်းတူနေတဲ့ စာလုံးတွေကို (၁) သရသက်သက် ➔ (၂) အသတ် ➔ (၃) ဗျည်းတွဲ ဆိုပြီး အုပ်စု ၃ စု ခွဲလိုက်ရင် လုံးဝ မမှားတော့ဘူး။ ပင့်/ရစ်/ဆွဲ/ထိုး ပါသမျှ အနောက်ဆုံးအုပ်စုကို တန်းပို့ပါ။

ကော်လံ (၁) • အရှေ့ဆုံး သရသက်သက်

ရိုးရိုးဗျည်း + သရသက်သက်

ဗျည်းတွဲလည်းမပါ၊ အသတ်လည်းမပါတဲ့ သရသက်သက် စာလုံးတွေက အမြဲတမ်း အရှေ့ဆုံးမှာ လာပါတယ်။

အ ➔ အာ ➔ အိ ➔ အီ ➔ အု ➔ အူ ➔ အေ ➔ အဲ ➔ အော ➔ အို
ဥပမာ - ကာ ➔ ကိ ➔ ကု ➔ ကူ ➔ ကေ ➔ ကဲ ➔ ကော ➔ ကို
⚠️ သတိပြုရန်: "ကော် (ေ-ာ်)" သည် အသတ်မဟုတ်ပါ၊ "အော" သရသာ ဖြစ်သည်။
ကော်လံ (၂) • အလယ် အသတ်စဉ်

ရိုးရိုးဗျည်း + အသတ် (-် / -ံ)

သရသက်သက်တွေ အကုန်ပြီးမှ အသတ်ပါတဲ့ စာလုံးတွေကို ဗျည်းအစဉ် (က မှ မ + သေးသေးတင်) အတိုင်း စီပါ။

က် ➔ င် ➔ စ် ➔ ဉ်/ည် ➔ တ် ➔ န် ➔ ပ် ➔ မ် ➔ ယ် ➔ ံ
ဥပမာ - ကောက်(က်) ➔ ကောင်း(င်) ➔ ကိစ္စ(စ်) ➔ ကန်(န်) ➔ ကံ့(ံ)
အသံတူရင်: အောက်မြစ် (-့) ➔ ရိုးရိုး ➔ ဝစ္စပေါက် (-း)
ကော်လံ (၃) • အနောက်ဆုံး ဗျည်းတွဲစဉ်

ဗျည်းတွဲ (ပင့် • ရစ် • ဆွဲ • ထိုး)

သရနဲ့ အသတ် ဘာပဲပါနေပါစေ ပင့်၊ ရစ်၊ ဆွဲ၊ ထိုး တစ်ခုခု ပါတာနဲ့ ရိုးရိုးဗျည်းအားလုံးရဲ့ အနောက်ကို တန်းပို့ပါ။

ပင့် (-ျ) ➔ ရစ် (ြ-) ➔ ဆွဲ (-ွ) ➔ ထိုး (-ှ) ➔ နှစ်ခုတွဲ (ြ-ွ)
ဥပမာ - ကျောင်း(-ျ) ➔ ကြက်(ြ-) ➔ ကွမ်း(-ွ) ➔ ကြွက်(ြ-ွ)
💡 နှစ်ခုတွဲ (ဥပမာ ကြွက်) သည် တစ်ခုတွဲအားလုံး၏ အနောက်ဆုံး၌ လာသည်။

ဗျည်း (၃၃) လုံး အစဉ် ဇယား (မေ့သွားရင် ကြည့်ရန်)

၅ လုံး တစ်တွဲ (ဝဂ်အလိုက်) မှတ်ထားရင် စာမေးပွဲမှာ အရမ်းမြန်ပါတယ်
